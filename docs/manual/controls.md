# Controls

The game is played with the mouse. The one key is **Esc**.

## In orbit

| Action | Control |
|---|---|
| Turn the planet | Drag with the left mouse button; flick to set it spinning |
| Zoom | Mouse wheel |
| Go down to a settlement | Click its marker, then **Go down** (or **Open** in the Settlements list) |
| Choose where to found a settlement | After **Found a city** or **Found an outpost**, click the planet |
| Open the game menu | **Menu** (bottom right) or **Esc** |
| Open the objectives | **Objectives** (bottom right, above **Menu**) |
| See what needs you | **Alerts** (bottom right, beside **Menu**) |
| See the charts of the planet and each city | **Statistics** (bottom right, beside **Alerts**) |
| Go to where an alert happened | Click the alert, in **Alerts** or as it pops up |
| Dismiss a pop-up alert | **x** on it |
| Put the guide away | **Skip the guide** on its card |
| Cancel founding | **Esc** or **Cancel** |

Left alone for a few seconds, the planet turns slowly by itself.

## In a city

| Action | Control |
|---|---|
| Move around | Drag |
| Zoom | Mouse wheel |
| Place a building | Choose its card, then click the ground |
| Select a building or rock | Click it |
| Lay corridors, cables or railway | Choose the tool, then drag; start on an existing link to remove links |
| Put down the chosen tool, or deselect | **Esc** |
| Scroll the build bar | Mouse wheel over it, or drag its scrollbar |
| Open the game menu | **Menu** (top right) |
| Open the objectives | **Objectives** (top right, under **Menu**) |
| See what needs you, or the charts | **Alerts** and **Statistics** (top right, beside **Menu**) |

## In the city planner

| Action | Control |
|---|---|
| Use the chosen tool | Drag with the left mouse button |
| Move around | Drag with the middle mouse button (or choose **Move**) |
| Zoom | Mouse wheel |
| Show where a service reaches | Click **Green space**, **Medical care**, **Research**, **Transport** or **Shops** in the **Coverage** row; **Off** hides it (a world made from Update 32 on) |

## On the world map

| Action | Control |
|---|---|
| Move around | Drag |
| Zoom | Mouse wheel, from the whole planet down to a single city's land |
| Select a settlement | Click it |
| Cancel laying a railway | **Esc** |

## Game speed

The speed buttons sit at the top of the orbit panel.

| Pace or mode | Speeds |
|---|---|
| Standard pace | pause, 1x, 2x, 3x |
| Classic pace | pause, 1x, 10x, 100x, 1000x |
| Sandbox | every speed |

Opening the game menu pauses the world; closing it goes back to the speed you had.

## The game menu

**Resume**, **Save**, **Settings** (not available yet) and **Save and quit to title**. On the
Example planet nothing is saved, so the last button is just **Quit to title**.
